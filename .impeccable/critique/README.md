# Critiques

Impeccable `critique` runs on Forge's surfaces: design reviews of screenshots
(Assessment A only; Forge is native Rust/GPUI, so the web detector does not
apply). Each file is one surface: its latest scores first, earlier runs below,
so the trend reads top to bottom. Priorities: P0 blocking, P1 before release,
P2 next pass, P3 polish.
