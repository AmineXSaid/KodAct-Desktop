# Rubric for the expert skill

Score each answer 0, 1 or 2 per row (0 absent, 1 partly, 2 fully). Grade blind.

| Row | What earns 2 |
|---|---|
| Level fit | Depth and vocabulary match the learner; terms defined only when needed |
| One objective | Says what the learner can do after; at most 3-4 new ideas |
| Concrete first | A worked example (from their code when possible) comes before the rule |
| Built in order | No idea used before it is introduced |
| Misconception | The usual wrong model is named and broken |
| Retrieval | 1-3 questions answered from memory, answers collapsed |
| Feedback (eval 6) | Says what is right, names the misunderstanding, one next step |
| Respects the ask | "Just the answer" gets only the answer; Socratic withholds the answer |
| Length | No wall of text; nothing that doesn't serve the objective |
| Correctness | No simplification that is false |

Old style vs. skill: report the mean per row and overall, and the evals where
each won.
